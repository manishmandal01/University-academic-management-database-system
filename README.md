# DBMS Capstone Project - University Academic Management System

## Project Description

The University Academic Management System is a relational database designed to manage departments, students, faculty, courses, enrollments and examination results. It replaces fragmented manual records and spreadsheets with a centralized, normalized (up to 3NF) database that maintains referential integrity and supports efficient SQL queries and academic reporting.

## Technologies Used

* Oracle SQL (DDL syntax) / PostgreSQL (online playground used for query outputs)
* GitHub

* ER Model

* Foreign Keys
* Constraints (NOT NULL, UNIQUE, CHECK, DEFAULT)
* DDL
* DML
* DQL
* CRUD
* Joins
* Aggregate Functions
* GROUP BY
* HAVING
* Sorting (ORDER BY)
* Pattern Matching (LIKE)
* NULL Handling (IS NULL / IS NOT NULL)
* Referential Integrity

## Database Entities

| Entity | Description |
|---|---|
| Department | Stores department information |
| Student | Stores student records |
| Faculty | Stores faculty details |
| Course | Stores course information |
| Enrollment | Represents student course registration |
| Result | Stores examination results linked to an enrollment |
